# Audit & Riset — opencode-termux — 2026-10-16

Semua fakta di bawah diambil dari sumber publik yang **benar-benar diakses** pada
2026-10-16 (WIB) atau dari unduhan nyata dengan sha256 dihitung lokal. Tidak ada
klaim tanpa sumber.

## 1) Kanal distribusi upstream opencode v2

- CLI opencode **v2 (2.0.x) tidak ada di npm registry**. Yang tersedia di npm:
  `opencode-ai` latest = **1.19.2** dan `opencode-linux-arm64-musl` latest =
  **1.19.2** (fetched: `registry.npmjs.org/opencode-ai/latest`,
  `.../opencode-linux-arm64-musl/latest`, 2026-10-16). Baris v1 saja.
- GitHub `sst/opencode` sekarang **redirect ke `anomalyco/opencode`**
  (API 2026-10-16); release terbaru `v1.19.2` (published 2026-10-16T02:30:23Z).
  Baris v2 juga tidak lewat releases GitHub.
- Distribusi v2 = **CDN saja**: `https://opencode.ai/files/bin/<V>/opencode-linux-<arch>-musl.tar.gz`.
  Tidak ada listing direktori (`/files/bin/` → 404, 2026-10-16) dan **tidak ada
  checksum yang dipublikasikan** CDN.
- Konsekuensi desain (sudah diterapkan): karena upstream tidak menerbitkan
  checksum, kit mem-pin **sha256 lokal** di `lib/integrity.mjs` (`BIN_PINS`),
  dihitung dari unduhan nyata:

  | versi/arch | sha256 (dihitung lokal dari CDN) |
  |---|---|
  | 2.0.21/arm64 | `2b91209518e7ee8b4e21022fa4a6f93b2f2514897cf125b0caf85979c997a97a` |
  | 2.0.30/arm64 | `ff021dca8e4127154596324f2f5a82a5b8983fb530daf803dcf8140a149f3e19` |

- **Lag terukur**: kit (working tree) masih mem-pin upstream **2.0.21**,
  sementara CDN sudah menyediakan **2.0.30** (keduanya diunduh utuh dan
  diverifikasi, 2026-10-16). Bump pin diserahkan ke workflow `sync-upstream`
  (cron mingguan, Senin) — bukan manual — supaya rilis teruji otomatis.

## 2) Lingkungan Termux/Alpine (dari instalasi nyata, 2026-10-16)

- Resolver Alpine memilih **v3.24** (latest stable; sebelumnya fallback v3.21).
- Paket yang dipakai: `libgcc 15.2.0-r5`, `libstdc++ 15.2.0-r5`,
  `patchelf 0.18.0-r3`.
- **Bug nyata tertangkap drill install**: Alpine v3.24 mengirim file
  `libstdc++.so.6.0.34`, sedangkan kode lama meng-hardcode `6.0.33` → ENOENT →
  instalasi gagal total. Fix: deteksi nama file dinamis + symlink soname
  `libstdc++.so.6` (terbukti lolos di install nyata, log `.latih/real-install.log`).
