# 🚀 v1.18.24 — Rilis Pertama

**opencode CLI native di Termux/Android — tanpa proot, tanpa root.**

Untuk pertama kalinya, [opencode](https://opencode.ai) berjalan native di Termux
tanpa proot-distro dan tanpa root — lewat loader musl libc yang dibangun khusus.

## ✨ Yang dibawa versi ini

- 📦 **Binary resmi** `opencode-linux-arm64-musl` dari upstream opencode-ai — tidak dimodifikasi
- 🔧 **Loader musl libc** hasil build khusus Termux:
  - path `/etc/resolv.conf` & `/etc/hosts` dipatch ke `$PREFIX/etc/` — DNS jalan tanpa root
- 🧩 **Shim Node.js**: `opencode-termux` → `ld-musl` → `opencode` (satu perintah, langsung jalan)
- 🧹 **LD_PRELOAD termux-exec dibersihkan** otomatis (tidak kompatibel dengan musl)

## 🚀 Install

```bash
pkg update && pkg install nodejs-lts
npm i -g @nemoobc/opencode-termux
```

> Jika muncul warning `install-scripts`, izinkan sekali:
>
> ```bash
> npm config set allow-scripts=@nemoobc/opencode-termux --location=user
> npm rebuild -g @nemoobc/opencode-termux
> ```

## ✅ Verifikasi

```bash
opencode-termux --version
```

Alias biar terasa asli:

```bash
ln -sf $PREFIX/bin/opencode-termux $PREFIX/bin/opencode
```
