# 🔧 v1.18.26 — Stabilisasi

Pemantapan dari rilis pertama — fokus keandalan jaringan & instalasi.

## 🛠️ Perbaikan & pemantapan

- 🌐 **Patch DNS diperkuat** — `/etc/resolv.conf` & `/etc/hosts` otomatis dibuat
  di `$PREFIX/etc/` saat instalasi (nameserver 1.1.1.1 & 8.8.8.8) — DNS pasti jalan
- 🧪 **Smoke test otomatis** — `opencode --version` dijalankan di akhir instalasi;
  gagal = instalasi ditandai gagal (tidak ada "terinstall tapi error diam-diam")
- 🧹 **LD_PRELOAD dibersihkan** sebelum eksekusi — `termux-exec` bawaan Termux
  tidak kompatibel dengan loader musl (penyebab error relokasi diam-diam)

## 🚀 Install

```bash
pkg update && pkg install nodejs-lts
npm i -g @nemoobc/opencode-termux
```

> Jika muncul warning `install-scripts`, izinkan sekali:
>
> ```bash
> npm config set allow-scripts=@nemoobc/opencode-termux --location=user
> npm rebuild -g @nemoobc/opencode-termux
> ```

## ✅ Verifikasi

```bash
opencode-termux --version
```
